# AI Coding Agent Directives & UI/UX Preservation Rules

## Core Rule: UI/UX & Design Preservation
- **Preserve Current Design & UI/UX**: Under no circumstances should the design, visual layout, theme, color scheme, typography, card structures, navigation patterns, or component aesthetics be redesigned, replaced, or broadly altered.
- **Surgical Edits Only**: When changes, features, or bug fixes are requested, only apply the precise, targeted modifications specified by the user. Keep all existing visual styling, UI components, responsive classes, and layout structures intact.
- **Bilingual & State Continuity**: Maintain support for both Indonesian and English locales (`LanguageContext` and `translations.ts`) and preserve existing state and repository architectures.
